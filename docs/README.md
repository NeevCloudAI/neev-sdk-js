# Documentation

The full NeevCloud documentation lives at <https://docs.ai.neevcloud.com>. This directory
holds the `@neevcloud/sdk` guides and reference.

New here? Start with **[Getting started](./getting-started.md)**.

| Document | What you'll find |
| --- | --- |
| [Getting started](./getting-started.md) | Install, configure credentials, and run your first sandbox |
| [Sandboxes](./sandboxes.md) | Commands, files, code interpreter, terminals, preview URLs, egress, snapshots, audit trail and more |
| [Agents](./agents.md) | Ready-made coding agents, such as Claude Code |
| [Agent tools](./agent-tools.md) | Sandbox tools for the agent you build, and adapters for agent frameworks |
| [Configuration](./configuration.md) | Credentials, organization and project scope, client options, timeouts and the raw client |
| [Errors](./errors.md) | Error classes, error codes and when to retry |
| [API reference](./api-reference.md) | Every method, grouped by product, with snippets |
| [API inventory](./api-inventory.md) | Exhaustive signatures, parameter tables, types and errors |
| [Use from an AI agent](./ai-agents.md) | Prompts to paste into a coding agent, and the rules it follows to use the SDK |
